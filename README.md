# Neurito – My Artificial Brain

Neurito es un proyecto donde una mascota virtual usa una red neuronal hecha con NumPy.
En el ejercicio 2, Neurito aprende a saltar obstáculos en un juego hecho con Pygame.

## Archivos
- `ejercicio_1.md`: experimentos del ejercicio 1.
- `ejercicio_2.md`: experimentos del ejercicio 2 (juego de salto).
- `GUIA_SALTO.md`: guía del juego de salto.
- `saltar.py`, `salto_juego.py`, `salto_modelo.py`: código del juego y de la red neuronal.

## Cómo ejecutarlo
    uv sync
    uv run saltar.py
